S1: Foundation and Reset

Reset Note: We utilize a compact selective reset rather than a global wipe. Key decisions include:

  • Box-Sizing: Enforcing box-sizing: border-box universally to make padding and border calculations predictable.
  • Selective Margins: Stripping default browser margins strictly from layout containers (like body and headings) while preserving useful spacing semantics elsewhere.

S2: Token Inventory

Core custom properties defined on :root:

  • --color-bg: Page canvas background
  • --color-surface: Card / container surface background
  • --color-text: Primary body text color
  • --color-action: Primary interactive accent color
  • --measure-max: Optimal readable line length (65ch)
