2. EVIDENCE-BASED REVISION
- Initial Observation: During mobile viewport testing (320px), some card margins felt slightly cramped against the screen edges.


- Revision: Adjusted spacing tokens to use 
scalable relative spacing (--space-sm and --space-md), and added fluid padding rules to the parent `.specimen-section` containers.


- Retest Result: Retested at 320px; the containers now breathe properly with comfortable inner margins and zero horizontal scroll.


3. CODE DEFENSE


- Reset Strategy: I chose a compact selective reset rather than a global reset and used universal box-sizing: border-box for sizing 


- Token Hierarchy: Organized custom properties on :root into logical groups (colors, typography, layout measures, spacing, and radius) using consistent semantic naming conventions 


- Scoped Alternate Theme: Implemented .theme-alt  as a scoped container override. By overriding token values (--color-bg, --color-surface, --color-text, etc.) inside that scope, all shared component rules apply automatically without requiring duplicate CSS code.
